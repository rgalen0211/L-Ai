# L-Ai session notes

## Live status file (standing rule)

The Ryagram web work in this repo runs as the WEB session. Keep a live status
file outside the repo so it never dirties the tree:

`C:\Users\Ryan\Ryagram-logs\status\WEB.md` (siblings: `CC1.md`, `RENDERER.md`)

Update it at every milestone: start of a task, each commit, anything blocked,
anything that needs Ryan. Keep it short and overwrite it; don't append forever.

- Now: what you're doing
- Last commit: hash + one line
- Blocked on / waiting for: who or what
- Needs Ryan: decisions or actions, with exact paths
- Files for Ryan to watch or review: exact paths

For each milestone, also append a one-line timestamped entry to
`C:\Users\Ryan\Ryagram-logs\status\log.md`.

Ryan's planning chat reads these files directly. Create the folder if it doesn't
exist.
