Connect your AI to Ryagram

If you use an AI assistant such as Claude or ChatGPT, you can let it work with your Ryagram account: ask it to start a project, save its story, make a contact sheet or a short preview, and check progress. You stay in charge, and you can disconnect it at any time.

What you need

  • A Ryagram account that has been invited to try connections.
  • An assistant that lets you add an outside tool by address. Not every plan of every assistant does (see below).
  • The Ryagram connector address: https://CONNECTOR-ADDRESS-PENDING.example/mcp (a placeholder; the real address is added when connections open).

What your AI can and cannot do

  • It can see your projects and credit balance, create projects, check and save a film's story, and make contact sheets and use your free previews, within a daily limit.
  • It cannot start a full render. Full renders are always started by you, in Ryagram.
  • It cannot change your account (your email, password or settings) or delete anything for you.
  • It cannot spend your credits. If something would cost credits, your AI is refused and you start it yourself in Ryagram.
  • The first time it connects, a Ryagram page asks you to sign in and shows the name Ryagram knows the assistant by, the name it calls itself, and the web address it will send you back to. Press Allow only if these match the assistant you are using.

Claude (claude.ai, Claude Desktop, phone)

  1. Open Customize, then Connectors, then Add custom connector.
  2. Name it Ryagram. For the address, paste https://CONNECTOR-ADDRESS-PENDING.example/mcp. Leave any client id and secret empty. If Claude asks how it should identify itself, choose Register automatically.
  3. Press Add, then Connect. Sign in to Ryagram, check the page says Claude, then press Allow.
  4. In a chat, turn the Ryagram connector on and try: "Using Ryagram, show my credits."

On a Claude Team plan only Owners and Primary Owners can add a custom connector. On Enterprise, Owners, Primary Owners and people with a custom role that includes Manage access to Libraries can. Once an admin has added it, each person connects and turns it on for themselves. Source: Anthropic’s help page on custom connectors.

Claude Code

  1. In a terminal, run claude mcp add --transport http ryagram CONNECTOR-ADDRESS-PENDING (the placeholder address again).
  2. Inside Claude Code run /mcp, choose ryagram, and press Authenticate. A browser opens for the Ryagram sign-in.

ChatGPT

This works only on plans that allow custom MCP connectors. Look in Settings, then Apps or Connectors: if there is an option to add a custom MCP server (sometimes behind Developer mode), you can use it. If there is not, ChatGPT cannot connect to Ryagram on your plan; use the Ryagram app directly.

  1. In Settings, Apps or Connectors, choose Create (custom MCP). Name it Ryagram, paste https://CONNECTOR-ADDRESS-PENDING.example/mcp, and choose OAuth for authentication.
  2. Accept the notice about custom servers, then Create and Connect. Sign in to Ryagram, check the address, and press Allow.
  3. ChatGPT asks you to confirm actions that save or start something. Read what it will do before you confirm.

Use the connector option above, not a Custom GPT.

Other assistants

Google Gemini, Microsoft Copilot Studio, Grok, Perplexity and Mistral Le Chat can add an outside tool in some plans; step-by-step guides for them are coming. Some assistants, such as Meta AI, the DeepSeek app and the consumer Microsoft Copilot, cannot add an outside tool at all. The Ryagram app has its own built-in editor that works without any connection.

Disconnecting

To stop an assistant, remove the Ryagram connector in that assistant's own settings. [DRAFT: Ryagram's own Disconnect button, under Account, arrives with connections.] A sign-in request lasts 30 minutes; if it runs out, start again from your assistant.
