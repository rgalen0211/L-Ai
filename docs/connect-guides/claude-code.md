# Claude Code

    claude mcp add --transport http ryagram <CONNECT_URL>

Then run `/mcp` inside Claude Code, choose ryagram, and Authenticate. A browser opens for the Ryagram sign-in and consent. The redirect is `http://localhost:<port>/callback` (loopback is on the allowlist).
