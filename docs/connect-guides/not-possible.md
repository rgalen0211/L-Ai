# Assistants that cannot connect (as of 2026-10-17)

- **Meta AI**: no way for a user to add an outside tool by address. Meta runs an invitation-only developer preview for connectors; there is nothing for friends.
- **DeepSeek (app)**: no connector or plugin feature found. The DeepSeek model can be used inside a tool that does support connections (for example Claude Code with DeepSeek as the model); that tool then connects to Ryagram.
- **Microsoft Copilot (consumer, copilot.microsoft.com)**: only Microsoft's own connectors. Copilot Studio can (see copilot-studio.md).

If you use one of these, use the Ryagram app directly; its built-in editor works without any connection.
