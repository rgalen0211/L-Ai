Every film is checked against its data. If the picture and the numbers disagree, it doesn’t get published.

Correctness checks

Checked before it’s published.

An animated chart can mislead without a single wrong number: a skipped month, a period shown twice, a label that doesn’t match its source. Ryagram checks for that before rendering.

  • Honest axes. Bars start at zero, so a bar’s length is its value.
  • Every number traced. Each figure on screen matches its published source at every year mark, checked frame by frame.
  • Uncertainty stated. When survey error is larger than a change, the film says so on screen.
  • Repeatable. Every film carries a receipt, and it rebuilds exactly from its project file and the code version that drew it.

Honest labels. Sample or synthetic data is marked as such on every frame.
